# Controle de Níveis de Água

## Descrição
Programa simples desenvolvido em Python para simular o monitoramento dos níveis de água de um reservatório.

O sistema mostra cinco níveis de água, cada um com uma mensagem e uma cor diferente no terminal.

## Tecnologias utilizadas
- Python
- Biblioteca Colorama

## Funcionamento
O programa utiliza uma lista com cinco níveis de água e uma função para definir a cor de cada situação.

As mensagens são exibidas no terminal, utilizando vermelho, amarelo, verde, ciano e azul.

## Como executar
1. Instale o Python.
2. Instale a biblioteca com `pip install colorama`.
3. Execute o arquivo com `python main.py`.

## Objetivo
Praticar o uso de listas, funções e bibliotecas em Python.
